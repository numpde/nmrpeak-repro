nmrpeak-repro

Deploy NMRPeak as a service that processes jobs from the NMR API and returns candidate molecular structures.

Source code

Inputs and results

The provider connects NMR API jobs to two NMRPeak analysis offerings:

  • nmrpeak_hf_v1: a molecular formula and a proton (1H) NMR peak list.
  • nmrpeak_chf_v1: a molecular formula, a proton (1H) NMR peak list, and a carbon-13 (13C) NMR peak list.

Each proton peak needs a chemical shift or shift range, an integral, and a multiplicity; include coupling constants when reported. Each carbon peak needs a chemical shift. The provider uses a configured language-model service to interpret the job’s input text before running NMRPeak.

Results contain candidate structures represented as SMILES strings. They are model predictions; the provider does not establish the compound’s identity or report a confidence score.

Check the software

You need Git, Make, and Python 3.11 or later, including venv and pip. Clone the repository and its pinned dependencies, then prepare a Python environment:

git clone --recurse-submodules https://github.com/numpde/nmrpeak-repro.git
cd nmrpeak-repro
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.lock
make test PYTHON=.venv/bin/python

Cloning and installing dependencies require network access. The tests do not require network access, API credentials, or model weights. They check provider behavior, communication with the model processes, and repository consistency using test fixtures and the pinned source. Passing them does not demonstrate model accuracy or a working deployment.

Deploy the provider

Deployment requires Docker with Compose, built provider and model images, installed model weights, an NMR API provider credential, and a configured OpenAI-compatible language-model endpoint for interpreting input text. The model processes run on CPU in separate containers without network access; the provider communicates with the API and the interpreter endpoint.

After cloning, run make help for checkpoint preparation, image builds, deployment setup, and start/stop commands, including their required arguments. The Makefile also lists these commands online. The test commands above do not start a deployment.

Scientific references

  • Xu et al., NMRPeak: a ready-to-use intelligent system for molecular structure elucidation enabled by synergistic cross-modal learning (2026). This repository pins the authors’ official implementation.
  • Wang et al., NMRexp: A database of 3.3 million experimental NMR spectra, Scientific Data 12, 1954 (2025). The NMRPeak paper describes its experimental NMRexp and simulated MST-NMR datasets, including curation and training, validation, and test splits.

This repository maintains the provider deployment. The pinned upstream implementation also includes training scripts; see the NMRPeak paper and upstream project for training and data preparation.
