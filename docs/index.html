nmrpeak-repro

A deployment repository for an NMRPeak provider that generates molecular structures through the NMR API.

Source code and operator instructions

Analysis offerings

  • nmrpeak_hf_v1 generates structures from a molecular formula and proton NMR.
  • nmrpeak_chf_v1 generates structures from a molecular formula, carbon NMR, and proton NMR.

When deployed, each offering runs its pinned source and reviewed checkpoint in a separate networkless container. The provider handles signed NMR API communication and durable recovery of interrupted API attempts.

Running and verifying the provider

Start with the README and run make help in the repository for the maintained command list, required inputs, and operational boundaries.

The make test verification lane uses inert fixtures without network access, credentials, or checkpoints. It checks the provider and both runner protocols; it does not load released checkpoints or establish that a live deployment works.

Scientific references

  • Xu et al., NMRPeak: a ready-to-use intelligent system for molecular structure elucidation enabled by synergistic cross-modal learning (2026). This repository pins the authors’ official implementation.
  • Wang et al., NMRexp: A database of 3.3 million experimental NMR spectra, Scientific Data 12, 1954 (2025). NMRPeak uses a curated subset of NMRexp together with simulated MST-NMR data. The NMRPeak paper describes the curation and splits.

This deployment repository contains neither the training data nor the training pipeline.
